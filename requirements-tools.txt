# requirements-tools.txt — 「ツール実行時ランタイム」のライブラリ集合
#
# AIが生成するツールコード（Type1）が使ってよいライブラリの唯一の定義。
# ここに書いた内容が、以下すべてに自動的に反映される。
#
#   - サンドボックスイメージ（Containerfile が読み込む）
#   - AIに提示する許可リスト（ai_creator.py がこのファイルから生成する）
#
# ツールコードはすべてコンテナ内で実行されるため、ホストのvenvには不要。
# ホスト側で必要なライブラリは requirements.txt 側に書くこと。
#
# 以前は許可リストが ai_creator.py の CREATOR_PROMPT / FIX_PROMPT にも
# 散文でハードコードされており、ライブラリを1つ足すのに3箇所を直す必要があった。
# どれか忘れると「AIは使ってよいと思っているのにイメージに入っていない」
# （またはその逆）が起きるため、定義をここに集約している。
#
# 行末の「# ...」はAIへの説明文として使われる。
# 内容を変更すると、次回のサンドボックス実行時に自動で再ビルドされる
# （ハッシュはパッケージ指定のみから取るため、説明文だけの変更では再ビルドしない）。
#
# 「⚙️ 設定」タブの「ツール実行時ライブラリ」からGUIで編集できる。

ddgs             # DuckDuckGo検索
requests         # HTTPアクセス
beautifulsoup4   # HTML解析、bs4としてimport
pandas           # データ処理・集計
numpy            # 数値計算
